# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind and constructive. Harassment or abuse of any kind isn't tolerated.

To report unacceptable behaviour, contact the maintainer, [@thegauravgiri](https://github.com/thegauravgiri), through GitHub.
